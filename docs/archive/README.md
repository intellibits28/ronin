# Ronin Documentation Archive (Historical & Previous Phases)

This directory contains historical design proposals, phase roadmaps, and early implementation notes from earlier iterations of Ronin (v1.0 through v2.0 development phases).

These documents are preserved for historical context, evolution tracking, and architectural research, but **do not represent the active production codebase** of Ronin (v5.0+).
